# 大学学习资料汇总

山西大学 自动化与软件学院 测控技术与仪器专业 本科学习资料整理。持续更新中~~

[![GitHub repo size](https://img.shields.io/github/repo-size/myp-super/SXU-CK-Learning-materials)](https://github.com/myp-super/SXU-CK-Learning-materials)

## 关于本仓库

本仓库收录了本科阶段（大一至大三）期间积累的学习资料，涵盖课程笔记、期末试卷、实验报告、课程设计、竞赛材料及自学资源。适用于山西大学测控技术与仪器及相关专业（自动化、电子、电气等）的同学参考。

> **注意**：仓库中部分大文件（PDF/MP4/ZIP 超过 100MB）使用 [Git LFS](https://git-lfs.com/) 管理。
> 克隆时请确保已安装 Git LFS，否则只能下载到指针文件：
> ```bash
> git lfs install
> git clone git@github.com:myp-super/SXU-CK-Learning-materials.git
> ```
